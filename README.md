# 点点农场 · 复刻版

> 用 **一个 HTML 文件**复原童年学习机上的种田游戏。
> 作物数值、生长贴图、界面文案**全部来自快易典 T5 固件的逆向提取**，不是拍脑袋编的。

双击 `点点农场_复刻版.html` 就能玩——**不用装任何东西、不用联网、不用起服务器**。

---

## 一、先玩起来

| 想玩 | 怎么做 |
|---|---|
| 直接玩 | 双击仓库根目录的 `点点农场_复刻版.html` |
| 分享给别人 | 把这个 HTML 文件单独发过去即可（它是自包含的，图片全在里面） |

浏览器用 Chrome / Edge / 火狐 都行。进度会自动存在浏览器本地，**关掉再开还在**。

## 二、游戏内容

- **23 种作物**：白萝卜、玉米、草莓、苹果、蘑菇、杨梅…… 种子价、果实售价、产量、经验、成熟时间全部是固件里的真实数值
- **完整循环**：播种 → 浇水 / 施肥 → 生长 → 收获 → 进仓库 → 出售 → 回商城买种子 → 扩建土地
- **多季作物**：苹果、杨梅这类收获后**回到「大叶子」状态**重新开花结果（不是退回种子），这是从固件数据里推出来的原版机制
- **每种作物各自的生长阶段名**：蘑菇是「原基 → 菇蕾 → 幼菇」，大白菜是「幼苗 → 成株 → 卷心」，桃子甚至是先开花后长叶——都是固件里的原始名称
- **商城作物图鉴**：点「详情」能看到该作物的全部参数 + 固件原始生长贴图 + 每个阶段的时间间隔
- **控制台**：改点币、改等级、发种子发果实，方便测试和随便玩
- **等距立体农田**：15 块菱形地块沿边错开无缝拼接，严丝合缝嵌进背景里预留的农田位置

### 操作

- 左侧工具栏：铲除 / 浇水 / 种子包 / 化肥 / 收获
- 选中工具后点地块生效；**右键或 Esc 取消**，也可以点右下角的指针按钮
- 商城买种子 → 种子包里选种 → 点褐色地块播种
- 右上角可切时间流速（×1 / ×60 / ×300 / ×1000）和暂停。默认 ×300 是为了测试方便，想体验真实节奏请切 ×1

## 三、这些数据是怎么来的

游戏里的每一个数字和贴图都有出处，不是设计出来的。详见 [`docs/01-固件逆向笔记.md`](docs/01-固件逆向笔记.md)，要点：

- **作物参数**：来自固件资源 `T5AppRes.dat` 内 23 个 `FDVER1` 作物块（块头 +0x38 起的 16 个 u32），已与实机商店面板逐项核对一致
- **生长贴图**：178 帧从 `Tc / TS` 贴图格式解码还原（RGB565 主图 + 8bit 透明遮罩）
- **界面文案**：从 `T5app.upg` 的字符串区挖出原版商店面板文案，字段标签直接用原版措辞
- **阶段名**：作物块内 +0x1D8 起的 GBK 命名表，每作物一份，各不相同
- **重熟机制**：由「重熟 = 成熟 − 大叶子起点」这条在 13 个作物上零例外的关系反推得出

完整作物参数见 [`docs/02-作物数据表.md`](docs/02-作物数据表.md)。

## 四、仓库结构

```
点点农场-复刻版/
├─ 点点农场_复刻版.html     ★ 成品游戏（单文件、自包含、双击即玩）
├─ README.md
├─ LICENSE
├─ assets/                  素材：背景 / UI图标 / 地块 / 作物贴图 / 装饰品（339 张 PNG）
├─ data/
│  ├─ crops.json            23 种作物的完整参数（固件导出）
│  └─ stage_names.json      每作物的生长阶段名（固件导出）
├─ src/
│  ├─ build_game.py         从 assets/ + data/ 生成那个单文件 HTML
│  └─ gen_crop_table.py     生成 docs/02-作物数据表.md
└─ docs/
   ├─ 01-固件逆向笔记.md    数据怎么挖出来的
   ├─ 02-作物数据表.md      23 作物参数总表
   └─ 农场设计蓝图_紫玉版.png
```

## 五、重新构建（可选）

改了素材或想重新打包时：

```bash
python src/build_game.py      # 产物覆盖根目录的 点点农场_复刻版.html
python src/gen_crop_table.py  # 重新生成作物参数表
```

只需要 Python 标准库（json / base64 / os），无第三方依赖。
